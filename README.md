# simAI-DEMO

simAI 관제 화면(front)을 **서버·GPU 없이** 시연 흐름 그대로 돌려 보는 저장소입니다.
개발 서버를 켜면 msw 목이 REST·STOMP 를 흉내 내서, 시연 계정으로 작업 관리 → 세팅 → 구역 → 작업 전 확인 → 실시간 관제(경보) → 작업 종료 → 보고서 제출 → 히스토리까지 한 바퀴 돌 수 있습니다.

- 기준 코드: 팀 저장소 `S15P31A101` dev `d2c5a42e`(2026-11-19)의 `front/`
- 시연 흐름용으로 바꾼 곳은 모두 `simAI-DEMO` 주석이 달려 있고, 스위치는 `apps/admin/src/mocks/demoFlow.ts` 하나입니다(시험 vitest 는 원래 목 데이터를 그대로 씁니다).

## 실행

필요한 것: Node 24.19, pnpm 11(corepack)

```bash
corepack enable
pnpm install
pnpm dev
```

브라우저에서 http://localhost:5173 을 열고 **`demo` / `demo`** 로 로그인합니다(시연 계정).
이 저장소는 **시연 모드로만** 보입니다: 목 계정은 `demo` 하나이고, 실서버에 붙여도 로그인한 계정은 모두 시연 계정으로 봅니다(`features/demo/demoAccount.ts`).

## 시연 흐름

1. **작업 관리** 달력에서 오늘 → 「오늘 작업 준비」
2. **TBM 보고서** 「다음」 → 작업 내용 고르고 「저장하고 세팅 시작」
3. **세팅 1단계** 카메라 4대 모두 준비됨·각도 양호. 「새 맵 만들기」 그대로 「다음」 → 보정·생성 5단계가 10초 만에 차고 시연 교실 3D 맵이 뜸 → 「다음」
   - 「이전 맵 재사용」을 고르고 「다음」을 누르면 보정·생성 없이 바로 구역 단계로 갑니다(AI 초안은 몇 초 뒤 뜸)
4. **구역** AI 위험 구역 초안 「단상 개구부」 「수락」 → 「다음」(세팅 완료)
5. **작업 전 확인** AI 가 채운 TBM 보고서 · 가상 레이아웃 확인 → 「서명하기」에서 한 번 그리고 「서명 추가」(작업자1·2 서명이 같이 들어감) → 「완료」 → 「다음」(작업 시작)
6. **실시간 관제** 시연 교실 3D 맵 · 작업자 3명 · 단상 개구부 구역. 40초마다 경보가 울림(진입 예측 → 추락 위험 → 위험구역 진입 → 높이 확인 필요). 배너 「확인」, 카드 「CCTV로 확인」
7. 상단 「작업 관리로」 → **작업 종료** → 보고서에 종료 미팅이 채워짐 → 「보고서 제출」
8. 달력의 지난 날(17·18일)을 누르면 **히스토리** 다시보기(CCTV 타임라인 · TBM 보고서 · 이벤트 로그)

## 알아 둘 것

- 목 상태는 **새로고침하면 처음으로** 돌아갑니다(작업·세팅·서명 모두). 흐름 중에는 화면 안 버튼으로만 이동하세요.
- 브라우저 탭을 오래 숨겨 두면 msw 서비스 워커가 끊겨 API 가 404 가 될 수 있습니다. 그때는 새로고침.
- 실시간 CCTV·세팅 카메라 칸은 실제 영상 대신 모의 화면(교실 선 그림 + 작업자)이고, 히스토리 CCTV 는 테스트 패턴 영상입니다.
- 개발 도구 콘솔의 `simaiMock` 으로 상황을 흉내 낼 수 있습니다: `simaiMock.drop()`(연결 끊김), `simaiMock.outage('tier0')`, `simaiMock.markSetupDone()`(오늘 작업 세팅 건너뛰기) 등 — `apps/admin/src/mocks/startBackend.ts` 참고.
- 실서버에 붙이려면 `apps/admin/.env.local` 에 `VITE_API_MOCK=false`, `API_PROXY_TARGET=…` 을 적습니다(`.env.example` 참고).
